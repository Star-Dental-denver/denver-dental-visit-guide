# Star Dental Denver Visit Guide

An original bilingual patient-education library about preparing for urgent, weekend and Health First Colorado dental visits in Denver. It includes focused guides for tooth pain, swelling, broken teeth, lost crowns, childhood dental injuries, denture problems and appointment preparation.

The official Star Dental website remains the primary source for complete clinical, service and appointment information.

## Public guide sections

- Denver urgent and weekend visit planner
- Urgent dental problem checklist
- Tooth pain and swelling guide
- Broken tooth and lost crown guide
- Child dental injury checklist
- Weekend dental visit guide
- Broken or loose denture guide
- New-patient preparation checklist
- Health First Colorado dental visit checklist
- Spanish resource center and four Spanish guides
- Editorial sources and methodology
